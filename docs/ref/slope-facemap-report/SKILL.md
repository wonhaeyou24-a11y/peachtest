# 절토사면 Face Map 도면 → 엑셀 정리 스킬

절토사면(비탈면) 외관조사 현황도(Face Map) PDF 한 장을 받아서, 도면에 그려진
지시선(리더선)이 가리키는 손상·시설물의 실제 위치(연장 m)를 계산하고,
정해진 4개 시트 엑셀로 정리하는 반복 작업 절차다. 사용자는 비개발자이므로
코드를 보여주거나 설명하지 말고, 결과 엑셀 파일만 전달한다.

**결과물은 항상 4개 시트만 만든다**: `1.기본정보`, `2.손상현황`,
`3.시설물현황`, `4.사면형상정보`. 지반조사자료(RMR표 등)·범례 시트는
사용자가 명시적으로 다시 요청하지 않는 한 만들지 않는다 (2026-09 사용자 확정 사항).

## 전체 절차

### 0단계. 업로드 확인
`/mnt/user-data/uploads/`에서 PDF를 확인한다. PDF가 없다고 업로드했다고 말하면
먼저 실제로 존재하는지 확인한다.

### 1단계. 이미지화 및 방향 보정
```bash
pdftoppm -png -r 200 "input.pdf" page
```
결과 이미지를 열어 제목/글자가 세로로 누워 있으면(도면이 90도 회전된 채로
스캔/출력된 경우가 흔함) 다음으로 정방향으로 돌린다. 어느 방향(90 또는 -90)이
맞는지는 실제로 두 방향 다 만들어보고 텍스트가 똑바로 읽히는 쪽을 선택한다.
```python
from PIL import Image
img = Image.open('page-1.png')
img.rotate(90, expand=True).save('page-1-rotated90.png')
```
이후 모든 좌표 분석은 이 "정방향" 이미지를 기준으로 한다.

### 2단계. 연장(chainage) 축 눈금 좌표 보정 — 가장 중요한 단계
도면 하단(또는 상단)에 0부터 시작해 20m 또는 10m 간격으로 찍힌 연장 눈금자가
있다. 이 눈금자의 숫자 라벨이 위치한 실제 픽셀 x좌표를 코드로 찾아
"픽셀 → 실제 연장(m)" 변환식을 세운다. 절대 눈으로 대충 어림잡지 말고
아래처럼 프로그램으로 정밀하게 찾는다.

```python
import numpy as np
from PIL import Image
arr = np.array(Image.open('page-1-rotated90.png').convert('RGB'))
h, w, _ = arr.shape
# 축 눈금 숫자가 있는 행(대략적인 y범위)을 먼저 눈으로 크롭해서 찾은 뒤,
# 그 행에서 어두운(텍스트) 픽셀의 x좌표를 클러스터링한다
y0, y1 = <축 라벨이 있는 y범위>
band = arr[y0:y1]
dark_mask = np.all(band < 100, axis=-1)
cols = np.where(np.any(dark_mask, axis=0))[0]
# 인접한 x좌표를 그룹으로 묶어 각 숫자 라벨의 중심 x좌표를 구한다
```
찾은 라벨 중심 좌표들이 일정한 간격(등차수열)을 이루는지 확인하고, 이상치(다른
글자와 겹쳐 오검출된 값)는 스페이싱으로 걸러낸다. 최종적으로
`chainage(x) = 시작값 - (x - x0) / (픽셀간격/눈금간격m)` 형태의 선형 변환식을
만들고, 반드시 3~4개 지점에서 눈으로 재검증한다 (예: 0m 지점, 중간 지점,
끝 지점 픽셀이 도면상 실제 눈금선과 일치하는지 크롭해서 확인).

축이 세로 방향(높이)과 가로 방향(연장) 두 개가 있을 수 있으니, 반드시
**연장(chainage, 보통 000~수백 m로 표기)** 축을 사용해야 하며 높이(0~100m
같은) 축과 혼동하지 않는다.

### 3단계. 지시선(리더선) 라벨 하나씩 추적
도면 중앙의 비탈면 그림 위에 텍스트 라벨과 그로부터 뻗어나온 가는 선(지시선)이
있고, 그 선의 끝(화살표 촉, 원, 점 등)이 실제 위치를 가리킨다. 아래 순서로
전체 도면을 놓치는 라벨 없이 훑는다:

1. 전체 도면을 겹치는 3~5개 구간으로 나눠 2~3배 확대한 크롭 이미지를 만들고
   각각을 `view`로 확인하며 라벨과 지시선 끝점을 기록한다.
2. 지시선 끝점(원·점·화살촉)의 픽셀 좌표를 가능하면 색상 기반 코드 탐지로
   교차검증한다 (예: 빨간 원, 파란 누수 아이콘처럼 색이 고유하면
   `np.where` 색상 마스크로 클러스터 중심 좌표를 뽑아 2단계 변환식에 대입).
3. 겹치는 크롭끼리 같은 라벨이 중복 추출되지 않도록 좌표로 대조한다.
4. 소단(1~5소단 등) 폭이나 경사각처럼 "연장 위치"가 아니라 "비탈면 높이
   방향/전체 형상"에 해당하는 항목은 위치를 억지로 계산하지 않고
   4번 시트(사면형상정보)에 범위/형상 정보로만 기록한다.

### 4단계. 항목 분류
라벨 텍스트를 아래 기준으로 분류한다 (2번 항목이 손상 시트의 핵심):

- **손상(2.손상현황)**: 균열, 뜬돌, 퇴적물 집적, 체수, 누수, 낙석, 세굴,
  붕괴, 유실, 파괴(평면파괴/쐐기파괴), 단층 등 — "이상 징후·훼손"을 뜻하는 단어
- **시설물(3.시설물현황)**: 점검계단, 점검문, 낙석방지망/울타리/옹벽,
  쏘일네일링(SN), 록볼트, 격자블럭+앵커, 수평배수공, 시험위치(★) 등
  — 설치되어 있는 구조물·조사지점
- **사면형상정보(4.사면형상정보)**: 소단 폭, 경사각, 구간(1구간/2구간 등)
  연장, 단면도 상세 치수, 상부 자연비탈면 경사 등 — 위치가 아닌 형상 스펙
- **기본정보(1.기본정보)**: 표제란의 도면명·사면명·경사/경사방향·연장·높이·
  축척 등

같은 라벨이 여러 개(예: "균열 3EA")면 지시선이 3개면 3행으로 나눠 각각의
위치를 계산한다 (합쳐서 1행으로 뭉개지 않는다).

도면에 "1구간 L=140m", "2구간 L=183m"처럼 구간 경계 표기가 있으면, 각 손상의
위치값이 어느 구간에 속하는지 계산해 `구간` 열에 채운다 (2026-09 확정 사항,
`references/excel_template.md`의 2.손상현황 표 참고). 손상치수(규모)도 더 이상
"L=2.0m, CW=0.5mm" 같은 하나의 문자열로 합쳐 쓰지 않고, 측정값 단위로
규모구분/값(순수 숫자)/단위 열로 쪼갠다 — 마찬가지로 `references/excel_template.md`
에 정확한 열 구성이 정의되어 있으니 반드시 그대로 따른다.

### 5단계. 엑셀 생성
`/mnt/skills/public/xlsx/SKILL.md`를 먼저 읽고 그 지침(폰트, 재계산 등)을
따른다. 시트 구조·서식은 `references/excel_template.md`를 그대로 따른다
(제목/부제목 스타일, 헤더 색상, 표 구성, 하단 안내문구 포함). 완성 후
`scripts/recalc.py`로 검증하고 `/mnt/user-data/outputs/`에 저장한 뒤
`present_files`로 전달한다.

### 6단계. 위치값 신뢰도 안내
매번 결과를 전달할 때 "위치값은 도면을 픽셀 단위로 분석한 추정치로 ±1~2m
오차가 있을 수 있다"는 점을 간단히 언급한다. 사용자가 이미 여러 번 안내받았다면
매번 길게 설명하지 말고 한 줄로 짧게만 상기시킨다.

## 흔한 실수 (반드시 피할 것)

- 세로(높이) 축과 가로(연장) 축을 혼동해서 위치를 계산하는 것
- 눈금 라벨을 눈대중으로 읽고 코드 검증을 생략하는 것 — 반드시 픽셀 좌표
  기반으로 계산하고 최소 2~3곳을 재크롭해서 눈으로 재확인
- 지시선 끝점이 아니라 텍스트 라벨 위치를 좌표로 쓰는 것 (라벨은 보통
  실제 위치에서 떨어져 있고 선이 실제 지점을 가리킴)
- 소단 폭/경사각처럼 연장 위치가 없는 형상 정보를 억지로 손상 시트에
  위치와 함께 끼워넣는 것
- 지반조사자료·범례 시트까지 만드는 것 (2026-09 확정: 4개 시트만)

## 도면 유형 분기: 옹벽외관망도(패널형 도면)

절토사면 Face Map과 달리, "옹벽외관망도" 같은 패널형 도면(제목에 "외관망도",
"옹벽", 도면 안에 "누가거리"·"측점 NO."·"S1, S2..." 패널 구간 표시가 있는
경우)은 절차가 다르다 (2026-09 사용자 확정, 반복 적용 중):

- 도면이 여러 페이지(각 페이지 = 보통 2개 패널, 40m)로 나뉘어 있고, 페이지
  하단에 **누가거리(0.00, 20.00, 40.00...)와 측점(NO.0, NO.1...) 표가
  이미 인쇄되어 있어** 절토사면처럼 픽셀로 눈금을 재검출할 필요가 거의 없다
  — 그 표의 숫자를 그대로 읽는다.
- 각 페이지 하단의 "손상물량표"가 그 페이지에 실제로 표시된 손상 각각을
  번호(1,2,3...)로 나열한다. 이 번호는 도면 위 손상 심볼의 원 안 번호와
  대응되므로, 텍스트로 다시 옮기지 말고 표를 그대로 신뢰해도 된다.
- **위치는 절토사면처럼 m단위로 정밀 계산하지 않고, 손상이 속한 패널
  (S1, S2...) 단위로만 표기한다** (사용자가 명시적으로 "빠르고 실용적인"
  패널 단위 방식을 선택함). 각 손상 심볼이 도면상 좌/우 어느 쪽에 있는지
  (페이지의 앞쪽 절반=첫 패널, 뒤쪽 절반=두번째 패널) 정도만 육안으로
  판단하면 충분하다. `L=20.0m`처럼 패널 전체 길이와 같은 손상(주로 "이격")은
  그 패널 전체에 걸친 것으로 간주한다.
- 엑셀 구조는 동일하게 4개 시트를 만들되 내용을 조정한다:
  - `1.기본정보`: 도면명, 대상 구조물명, 총 연장, 패널 구성(S1~Sn, 마지막
    패널은 나머지 길이)
  - `2.손상현황`: 열 구성은 `구간(패널) / 위치(연장 범위, 예:
    "40.00~60.00m") / 손상명 / 규모구분1 / 값1 / 단위1 / 규모구분2 / 값2 /
    단위2`. 면적(A=가로x세로)으로 표기된 손상은 값1=가로, 값2=세로로 넣어
    둘 다 순수 숫자로 분리한다. 수량(EA)만 있는 항목은 규모구분1="수량",
    단위1="EA".
  - `3.시설물현황`: 도수로·배수관·배수구·암거박스·점검계단 등. 여러 곳에
    반복 표시되는 시설은 대표 위치 몇 곳만 적어도 된다.
  - `4.벽체형상정보`(절토사면의 "사면형상정보"를 이 도면 유형에서는 이렇게
    부른다): 소단/경사각 대신 패널별 연장(S1~Sn, 각 20.0m, 마지막 패널만
    나머지 길이)과 총 연장을 정리한다.
- 절토사면 도면인지 옹벽(패널형) 도면인지 애매하면, 도면 제목과 하단에
  "누가거리/측점" 표가 있는지로 먼저 판별한 뒤 사용자에게 굳이 되묻지 않고
  적절한 절차로 바로 진행한다.
