# 엑셀 출력 양식 (4개 시트 고정)

공통 스타일:
- 폰트: Arial 전체
- 제목: 14pt bold, 1행, A1부터 시트 폭만큼 병합
- 부제목(2행): 9pt, 회색(#595959) — "대상: <절토사면명>  |  연장 <FMS>/<실측>  |  높이 <h>  |  축척 V=1:1,000, H=1:1,000" 형태로 도면 표제란 값을 채워 넣는다
- 표 헤더행: 11pt bold, 흰 글씨, 배경 #4472C4, 가운데 정렬, 셀 테두리(연회색 얇은선)
- 데이터행: 10pt, 테두리, 짝수행은 배경 #F2F2F2 줄무늬
- 섹션 소제목(4번 시트 내부 구분용): 11pt bold, 흰 글씨, 배경 #8497B0
- 하단 안내문(※): 9pt italic 회색(#808080), 표와 2행 띄우고 시작, 줄바꿈(wrap_text) 적용

## 1.기본정보
2열 표 (항목/값): 도면명, 절토사면명(위치), 도면번호, 경사/경사방향, 연장,
높이, 축척, 구간별 연장(1구간/2구간 등 있는 만큼), 상부 자연비탈면 경사.
표제란에 없는 항목은 행 자체를 생략한다(빈 칸으로 채우지 않음).

## 2.손상현황
9열 표(2026-09 확정 양식): `구간` / `위치 (연장 m)` / `손상명` /
`규모구분1` / `값1` / `단위1` / `규모구분2` / `값2` / `단위2`.

- **구간**: 도면에 표기된 구간 경계(예: 1구간 0~140m, 2구간 140~323m처럼
  도면마다 다르게 표기된 구간 정보를 그대로 사용)를 기준으로, 위치값이 어느
  구간에 속하는지 판정해 "1구간"/"2구간"(또는 도면에 있는 구간 수만큼)으로
  채운다. 구간 정보가 도면에 없으면 이 열은 빈칸으로 둔다.
- **위치**: 기존과 동일(연장 눈금 픽셀 좌표 환산).
- **손상명**: "균열 (1소단측구)"처럼 [손상종류] ([발생위치/부재])로 통일.
- **규모구분1/값1/단위1, 규모구분2/값2/단위2**: 도면 표기값(예: "L=2.0m,
  CW=0.5mm")을 측정값 단위로 쪼갠다.
  - 규모구분: 등호 앞부분 그대로("L=", "CW=", "A=" 등)
  - 값: **단위를 뗀 순수 숫자만** (쉼표 등 천단위 구분자도 제거, 숫자 타입
    셀로 입력 — 예: "1,586.6㎡" → 값=1586.6). 사용자가 값만 그대로 복사해
    계산에 쓸 수 있어야 하므로 절대 문자열에 단위나 기호를 섞지 않는다.
  - 단위: "m", "mm", "㎡" 등 단위만 별도 열에 표기
  - 측정값이 하나뿐이면 규모구분2/값2/단위2는 공란
  - 규모 표기가 전혀 없는 손상(단순 누수 지점 등)은 규모구분1/값1/단위1을
    "-"로, 규모구분2/값2/단위2는 공란
- 위치가 큰 값(도면 시작쪽)부터 내림차순 정렬
- 표 하단에 ※ 안내문 필수, 최소 아래 4가지 포함:
  1) 구간 판정 기준 한 줄 설명
  2) 위치 산정 방법(연장 눈금 픽셀 좌표 환산) 한 줄 설명
  3) 오차 가능성(±1~2m) 고지
  4) 값1/값2가 순수 숫자인 이유(복사해 바로 계산에 쓸 수 있도록) 및 단위는
     별도 열에 있다는 안내

## 3.시설물현황
3열 표: `위치 (연장 m) / 범위` / `시설물·시험명` / `비고`.
- 점처럼 위치가 명확한 것은 "약 000m", 도면 전체에 반복되는 것은
  "전 구간(0~<연장>m)", 구간성 시설은 "약 A~Bm 구간"으로 표기
- 위치를 못 찾은 항목은 행 자체를 빼지 말고 "도면상 위치 불명확"으로 비고에
  명시 (누락처럼 보이지 않게)

## 4.사면형상정보
2열(항목/값) 표를 섹션 소제목으로 나눠 구성. 도면에 있는 것만 넣는다:
- ① 소단(berm) 구성 — 소단 번호별 폭
- ② 비탈면 경사각 — 단별 경사각(하부→상부), 평균경사, 상부 자연비탈면
- ③ 단면도 상세(있는 경우) — 총고, 토층심도, 단별 높이 등
- 마지막에 "소단은 연장 위치가 아니라 비탈면 단면 형상 정보"라는 취지의
  안내문 1줄

## 파일명 및 저장
- 파일명은 `<절토사면명 또는 도면명>_손상현황.xlsx` 형태로 자동 생성
  (예: `절토사면_손상현황.xlsx`). 절토사면명이 파일명에 쓰기 부적합한 문자를
  포함하면 안전한 형태로 정리한다.
- `/mnt/user-data/outputs/`에 저장 후 `present_files`로 전달
- 저장 전 `python /mnt/skills/public/xlsx/scripts/recalc.py <파일>` 로 검증
